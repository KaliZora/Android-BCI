# Android BCI Pipeline Orchestrator

An automated orchestrator that provisions the environment, installs system dependencies, and compiles a BrainFlow-based Brain-Computer Interface (BCI) pipeline into a native executable using Nuitka. Explicitly designed for Linux and Android (Termux).

## Features
- **Automatic Provisioning:** Installs required compilers (`clang`, `lld`, `patchelf`) and toolchains via `apt` or `pkg`.
- **AOT Native Compilation:** Builds a standalone binary via Nuitka including embedded native BrainFlow `.so` dependencies and Link-Time Optimization (LTO).
- **DSP Processing:** Features Butterworth bandstop (notch), bandpass filtering, and wavelet denoising (`BIOR3_9`).
- **URML Intent Gate:** Symmetrically evaluated alpha/beta dominance confidence gating.

## Requirements
- **OS:** Linux or Android (via Termux)
- **Python:** Version 3.10 or higher strictly required

## Usage

# Preview operations without running them
python3 bci_orchestrator.py --dry-run

# Run with physical hardware (e.g. OpenBCI Cyton)
python3 bci_orchestrator.py --board cyton --port /dev/ttyUSB0 --duration 20 --threshold 0.5

# Skip system package installation if already provisioned
python3 bci_orchestrator.py --skip-system-install
```
